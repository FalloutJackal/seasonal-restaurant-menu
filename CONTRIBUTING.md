# Contributing

Thank you for your interest in contributing to this project. This repository is an independent learning project, but suggestions, bug reports, accessibility improvements, and code contributions are welcome.

## Ways to Contribute

You can contribute by:

- Reporting layout or display problems
- Suggesting accessibility improvements
- Correcting documentation or spelling errors
- Improving responsive behavior
- Simplifying HTML or CSS without changing the intended design
- Suggesting improvements to code organization

## Before Making a Change

Before beginning a larger change, please open an issue explaining what you would like to change and why. Small corrections, such as spelling fixes, may be submitted directly through a pull request.

Please check existing issues before creating a new one to avoid duplicates.

## Development Guidelines

When contributing code, please:

- Preserve the semantic HTML structure
- Maintain accessible labels and navigation
- Follow the existing BEM naming convention
- Use Flexbox for the primary layout
- Maintain the existing CSS organization
- Keep the design responsive across narrow and wide screens
- Avoid adding libraries or frameworks unless discussed first
- Explain code that may not be immediately clear

## Testing Changes

Before submitting a pull request:

1. Open the project in a browser.
2. Check the layout at several viewport widths.
3. Confirm that text remains readable without horizontal overflow.
4. Verify that navigation links and interactive elements remain keyboard accessible.
5. Check that your changes do not unintentionally affect unrelated parts of the page.

## Submitting a Pull Request

When submitting a pull request:

1. Fork the repository.
2. Create a branch for your changes.
3. Make focused changes related to one issue or improvement.
4. Write a clear commit message.
5. Describe what you changed and why.
6. Include screenshots when the change affects the visual layout.
7. Link the related issue, if one exists.

## Code of Conduct

Please communicate respectfully and keep discussions focused on improving the project. Constructive feedback is welcome; harassment, personal attacks, and discriminatory behavior are not.
